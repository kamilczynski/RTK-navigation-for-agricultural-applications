
## Hardware

KDpath is built around a Raspberry Pi 5, combined with a dual-frequency GNSS RTK receiver, a touchscreen display, and portable power solutions.

The system is designed for field use, with a focus on precision positioning, portability, and future integration with automated steering hardware.

### Core Hardware

| Component | Model / Specification | Purpose |
|---|---|---|
| Single-board computer | Raspberry Pi 5 — 8 GB RAM | Main processing unit running KDpath |
| Cooling system | Raspberry Pi Active Cooler | Active cooling for the Raspberry Pi |
| Touchscreen display | Waveshare 10.1″ QLED IPS — 1280 × 720 | Navigation interface and touchscreen controls |
| Keyboard | USB keyboard | Manual input and system configuration |
| Mouse | USB mouse | Interface navigation and system control |
| GNSS RTK module | SparkFun GPS-RTK-SMA Breakout (GPS-16481) | High-precision GNSS positioning |
| GNSS receiver | u-blox ZED-F9P | Dual-frequency, multi-constellation RTK positioning |
| GNSS antenna | u-blox dual-frequency L1/L2 antenna | Reception of GNSS satellite signals |
| Power management module | Geekworm power module | Power management for the Raspberry Pi |
| Portable power supply | USB power bank | Mobile operation without a fixed power source |
| Portable power station | DJI Power 1000 V2 — 1024 Wh | Alternative power source and support for future steering hardware |

*Note: The u-blox ZED-F9P is integrated into the SparkFun GPS-RTK-SMA Breakout board. It is not a separate external module.*
